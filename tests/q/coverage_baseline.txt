# Functions the suite never enters, and why that is accepted for now.
#
# tests/q/run_coverage.q compares the whole-suite run against this list and
# FAILS when they disagree, in either direction:
#
#   a function never entered that is NOT listed   a new blind spot
#   a listed function that IS now entered         the list has gone stale
#
# Both are failures on purpose. A baseline that only ratchets one way rots:
# entries stay after the gap they described is closed, the list stops
# describing anything, and the next reader cannot tell which lines are still
# true. Removing a line is the cheaper half of closing a coverage gap.
#
# A name here is a statement that nothing in the suite CALLS the function -
# not that it is untestable, and not that it is unimportant. Several of these
# should simply be covered; they are listed because they are not, not because
# they should not be.
#
# Blank lines and lines starting with # are ignored.
