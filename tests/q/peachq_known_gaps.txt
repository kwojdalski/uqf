# A reason starts with its kind, and says why rather than what the test
# expects - a reason that repeats the test's own assertion message is refused

#   peachq-lacks: <the capability PeachQ lacks, as specifically as known>
#   tree-bug: #<issue>  - code here that relies on something it should not
#
# These are facts about the platform below - CI's PeachQ build. The same pin
# built elsewhere behaves differently, so on any other platform the lane
# reports a difference as not comparable rather than as a verdict (#968).
