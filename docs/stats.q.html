stats.q

stats.q - normal distribution helpers used throughout uqf. ncdf/npdf use the Abramowitz & Stegun 7.1.26 rational approximation to the error function (max absolute error ~1.5e-7). inv_ncdf uses Peter Acklam's rational approximation to the inverse standard normal CDF (max relative error ~1.15e-9), released by its author into the public domain. See: https://web.archive.org/web/20151030215612/http://home.online.no/~pjacklam/notes/invnorm/ .

.qstats.horner_eval

Evaluate a polynomial at x via Horner's method - the one place q's lack of operator precedence for hand-written Horner chains is worked out and tested, so no other formula in this repo has to re-derive it. See the kdb-q-conventions skill for why (`a*x+b` means `a*(x+b)` in q, not `(a*x)+b`, which silently broke early drafts of this function).

eg: .qstats.horner_eval[2 3 4;5] -> 69 (i.e. 2*5*5+3*5+4)
Return: coeffs[0]*x^n + coeffs[1]*x^(n-1) + ... + coeffs[n]
Parameters:
  • coeffs - polynomial coefficients, highest degree first, constant term last (as in numpy.polyval)
  • x - the point to evaluate the polynomial at

.qstats.inv_ncdf

Inverse standard normal CDF (probit function).

eg: .qstats.inv_ncdf 0.95 -> 1.644854 (the one-tailed 95% z-score)
Return: x such that ncdf[x]~p
Parameters:
  • p - probability, strictly within (0,1); an atom or a list of atoms
throws: error if any element of p is not strictly between 0 and 1

.qstats.ncdf

Standard normal cumulative distribution function N(x).

eg: .qstats.ncdf 1.96 -> 0.9750022
Return: P(Z is at most x) for a standard normal Z
Parameters:
  • x - point(s) to evaluate at (atom or vector)

.qstats.npdf

Standard normal probability density function n(x).
