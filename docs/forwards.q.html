forwards.q

forwards.q - FX forward/swap points via covered interest rate parity (CIRP), and rate/cross-rate helpers used on an eFX forwards desk. . Currency pair convention: a rate quoted BASE/QUOTE means 1 unit of BASE buys `rate` units of QUOTE (e.g. EURUSD 1.1000 -> 1 EUR = 1.10 USD). rd is the QUOTE currency's interest rate, rf the BASE currency's.

Entity Details

.qf.book_crossed

True if a book is crossed (bid > ask) - a sanity check for synthetic books built from cross_book/combine_oriented_books.

eg: .qf.book_crossed[`bid`ask!(1.1000;1.1002)] -> 0b
Return: 1b if bid>ask, else 0b
Parameters:
  • book - a dict `bid`ask!(bidPx;askPx)

.qf.ccy_orient_cross

Private: work out how two currency pairs relate - which currency they share, what the resulting cross pair's symbol is, and whether either leg needs inverting before combining - without touching any prices. Shared by cross_book and cross_book_at_sizes so the two can never disagree about orientation.

eg: .qf.ccy_orient_cross[`EURUSD;`USDJPY] -> `cross_sym`invert1`invert2!(`EURJPY;0b;0b)
Return: dict `cross_sym`invert1`invert2 - cross_sym is the resulting pair symbol; invert1/invert2 say whether that leg's quote convention needs flipping (BASE/QUOTE -> QUOTE/BASE) before combining
Parameters:
  • sym1 - currency pair for leg 1, any format ccy.q's normalize_ccy_pair accepts
  • sym2 - currency pair for leg 2, any format ccy.q's normalize_ccy_pair accepts
throws: error if sym1 and sym2 share no common currency

.qf.combine_oriented_books

Combine two order books that are already oriented A/B and B/C (i.e. the quote currency of the first leg matches the base currency of the second) into a top-of-book A/C book. Private building block for cross_book; call directly if you've already oriented the legs yourself.

eg: .qf.combine_oriented_books[`bid`ask!(1.1000;1.1002);`bid`ask!(150.00;150.02)] -> `bid`ask!(165;165.052)
Return: dict `bid`ask!(bidPx;askPx) quoted A/C
Parameters:
  • book_ab - dict `bid`ask!(bidPx;askPx) quoted A/B
  • book_bc - dict `bid`ask!(bidPx;askPx) quoted B/C

.qf.cross_book

Build a synthetic top-of-book cross rate from two live order books on pairs that share a common currency, e.g. cross_book[`EURUSD;eurusd_book; `USDJPY;usdjpy_book] -> a synthetic EURJPY book. The shared currency is detected automatically and either leg is inverted as needed - the caller does not need to pre-orient anything. sym1/sym2 are normalized via ccy.q's ccy_pair_legs, so `eurusd, "eur/usd" etc. work too, not just canonical `EURUSD. Combines top-of-book only; it does not walk/net multiple depth levels of the underlying books - see cross_book_at_sizes for that.

eg: .qf.cross_book[`EURUSD;`bid`ask!(1.1000;1.1002);`USDJPY;`bid`ask!(150.00;150.02)] -> `sym`bid`ask!(`EURJPY;165;165.052)
Return: dict `sym`bid`ask!(cross_sym;bidPx;askPx) for the synthetic cross
Parameters:
  • book2 - dict `bid`ask!(bidPx;askPx) quoted in sym2's own convention
  • book1 - dict `bid`ask!(bidPx;askPx) quoted in sym1's own convention
  • sym1 - currency pair for book1, any format ccy.q's normalize_ccy_pair accepts
  • sym2 - currency pair for book2, any format ccy.q's normalize_ccy_pair accepts
throws: error if sym1 and sym2 share no common currency

.qf.cross_book_at_one_size

Private: bid, ask and mid for a 2-leg cross at a single size. mid is the average of the swept cross bid and the swept cross ask at that size (not a separate sweep of its own).

Return: one row: dict `size`sym`bid`bid_filled_size`bid_fully_filled`ask`ask_filled_size`ask_fully_filled`mid
Parameters:
  • book2 - dict `bid_prices`bid_sizes`ask_prices`ask_sizes for leg 2
  • book1 - dict `bid_prices`bid_sizes`ask_prices`ask_sizes for leg 1
  • size - the size to sweep, in leg 1's relevant currency
  • sym1 - currency pair for leg 1
  • sym2 - currency pair for leg 2

.qf.cross_book_at_sizes

Depth-aware synthetic cross rate: like cross_book, but walks multi-level order book depth on both legs for each requested size, converting the notional hop-by-hop (leg 2 is swept at the bridge-currency amount leg 1's sweep actually produced), and returns only the sides you ask for. Each leg's book must supply real depth, not just top-of-book - see sweep_price's book shape.

eg: .qf.cross_book_at_sizes[`EURUSD;eurusd_book;`USDJPY;usdjpy_book;1000000 3000000;`bid`ask`mid]
Return: a table, one row per size, columns `size`sym plus whichever of bid/bid_filled_size/bid_fully_filled, ask/ask_filled_size/ask_fully_filled, mid were requested via sides
Parameters:
  • book2 - dict `bid_prices`bid_sizes`ask_prices`ask_sizes for leg 2, each level best-first
  • book1 - dict `bid_prices`bid_sizes`ask_prices`ask_sizes for leg 1, each level best-first
  • sizes - list of sizes to price, e.g. 1000000 2000000 5000000
  • sides - subset of `bid`ask`mid to include in the result
  • sym1 - currency pair for leg 1, any format ccy.q's normalize_ccy_pair accepts
  • sym2 - currency pair for leg 2, any format ccy.q's normalize_ccy_pair accepts
throws: error if sym1 and sym2 share no common currency, or sides has anything other than `bid`ask`mid

.qf.cross_rate

Triangulate a cross rate: A/B * B/C = A/C.

eg: .qf.cross_rate[1.10;150] -> 165f (EURUSD * USDJPY -> EURJPY)
Return: the implied rate for A/C
Parameters:
  • ab_rate - rate for A/B
  • bc_rate - rate for B/C

.qf.cross_rate_shared_base

Cross rate via a shared base currency: given two pairs both quoted A/X and A/Y (e.g. EURPLN and EURUSD both quoted against EUR), returns the Y/X cross rate - the common eFX pattern of computing e.g. USDPLN from EURPLN and EURUSD as EURPLN * (1/EURUSD). Simply cross_rate composed with invert_rate; kept as its own named function because "invert the second one, not the first" is exactly the kind of thing that's easy to get backwards at the desk.

eg: .qf.cross_rate_shared_base[4.30;1.075] -> 4f (EURPLN, EURUSD -> USDPLN)
Return: the implied rate for Y/X
Parameters:
  • rate_ax - rate for A/X (the shared base A over the first quote currency X)
  • rate_ay - rate for A/Y (the shared base A over the second quote currency Y)

.qf.cross_sweep_side

Private: sweep one side of a 2-leg cross at one size, converting the notional hop-by-hop - leg 2 is swept at the amount of the shared/bridge currency that leg 1's sweep actually produced, not at the raw input size.

Return: dict `price`filled_size`fully_filled for this side of the cross
Parameters:
  • book2 - dict `bid_prices`bid_sizes`ask_prices`ask_sizes for leg 2
  • book1 - dict `bid_prices`bid_sizes`ask_prices`ask_sizes for leg 1
  • side - `bid or `ask - the side of the final cross being priced
  • size - the size to sweep, in leg 1's relevant currency
  • invert1 - 1b if leg 1 needs its convention flipped
  • invert2 - 1b if leg 2 needs its convention flipped

.qf.fwd_cont

Outright forward rate under continuous-compounding CIRP: F = S*exp((rd-rf)*t)

eg: .qf.fwd_cont[1.10;0.05;0.02;1] -> 1.1335
Return: the outright forward rate
Parameters:
  • rd - domestic (quote currency) decimal annual rate
  • rf - foreign (base currency) decimal annual rate
  • t - year fraction to the forward date
  • spot - spot rate, BASE/QUOTE

.qf.fwd_points

Forward points = (F-S) scaled into pips.

eg: .qf.fwd_points[1.132353;1.10;10000] -> 323.53
Return: the forward points, in pips
Parameters:
  • fwd - outright forward rate
  • spot - spot rate
  • pip_factor - 10000 for most pairs, 100 for JPY crosses

.qf.fwd_simple

Outright forward rate under simple-interest CIRP: F = S*(1+rd*t)/(1+rf*t)

eg: .qf.fwd_simple[1.10;0.05;0.02;1] -> 1.132353
Return: the outright forward rate
Parameters:
  • rd - domestic (quote currency) decimal annual rate
  • rf - foreign (base currency) decimal annual rate
  • t - year fraction to the forward date
  • spot - spot rate, BASE/QUOTE

.qf.implied_domestic_rate

Back out the implied domestic (quote currency) rate from an observed outright, given the foreign (base currency) rate - simple CIRP inverse.

eg: .qf.implied_domestic_rate[1.10;1.132353;0.02;1] -> 0.05
Return: the implied domestic (quote currency) decimal annual rate
Parameters:
  • fwd - observed outright forward rate
  • rf - foreign (base currency) decimal annual rate
  • t - year fraction to the forward date
  • spot - spot rate

.qf.implied_foreign_rate

Back out the implied foreign (base currency) rate from an observed outright, given the domestic (quote currency) rate - simple CIRP inverse.

eg: .qf.implied_foreign_rate[1.10;1.132353;0.05;1] -> 0.02
Return: the implied foreign (base currency) decimal annual rate
Parameters:
  • fwd - observed outright forward rate

  • t - year fraction to the forward date
  • spot - spot rate

.qf.invert_book

Invert an order book: BASE/QUOTE -> QUOTE/BASE. Inverting flips which side is more favourable, so the new bid comes from the old ask and vice versa.

eg: .qf.invert_book[`bid`ask!(1.1000;1.1002)] -> `bid`ask!(0.9089256;0.9090909)
Return: the same book quoted QUOTE/BASE
Parameters:
  • book - a dict `bid`ask!(bidPx;askPx) quoted BASE/QUOTE

.qf.invert_book_depth

Invert a multi-level depth ladder: BASE/QUOTE -> QUOTE/BASE. Prices invert elementwise (order stays best-first automatically: inverting a monotonic ladder reverses its sense exactly the way flipping ask<->bid requires). Sizes rescale into the new base currency - a level of size BASE units at price QUOTE/BASE is worth size*price QUOTE units, which become the new base currency's size.

eg: .qf.invert_book_depth[1.1000 1.1002;1000000 1000000] -> (0.9090909 0.9089256;1100000 1100200)
Return: (invertedPrices;rescaledSizes), still best-first
Parameters:
  • sizes - level sizes in the ladder's own base currency, aligned to prices
  • prices - level prices, best-first

.qf.invert_rate

Invert a quote convention: BASE/QUOTE -> QUOTE/BASE.

eg: .qf.invert_rate 2f -> 0.5
Return: the same rate quoted QUOTE/BASE
Parameters:
  • rate - a rate quoted BASE/QUOTE

.qf.oriented_levels

Private: the (prices;sizes) to sweep for one leg, for one side of the final cross. If this leg doesn't need inverting, that's just its own same-named side; if it does, it's the *other* original side, inverted (an inverted bid becomes an ask, and vice versa).

Return: (prices;sizes) to pass to sweep_price
Parameters:
  • side - `bid or `ask - the side of the final cross being priced
  • invert - 1b if this leg's convention needs flipping
  • book - dict `bid_prices`bid_sizes`ask_prices`ask_sizes for this leg

Parameters:
