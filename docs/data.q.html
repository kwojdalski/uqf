data.q

data.q - optional Databento parquet data access, keyed by symbol and date. Not loaded by src/init.q: it needs a real kdb+/KDB-X interpreter (PeachQ has no `2:`, so it can't load KX's native pq module) and a local .env pointing at the data. Load explicitly with `\l src/data.q`. Expects DATABENTO_DATA_DIR (from a repo-root .env file, or the OS environment) to point at a folder laid out as: //__raw_mbp-10_us_hours.parquet .

Entity Details

.uqfdata.cfg

Look up a config value: the OS environment first, then the parsed .env dict, then the given default.

eg: .uqfdata.cfg[`DATABENTO_DATA_DIR;::]
Return: the string value
Parameters:
  • dflt - fallback value, or generic null (::) to error if unset
  • k - the variable name, e.g. `DATABENTO_DATA_DIR`
throws: configMissing if k isn't set anywhere and no default was given

.uqfdata.databentoDir

Root folder for locally-available Databento parquet dumps (DATABENTO_DATA_DIR), one subfolder per symbol.

eg: .uqfdata.databentoDir[]
Return: the configured folder path, as a string
throws: configMissing if DATABENTO_DATA_DIR isn't set anywhere

.uqfdata.databentoFile

Expected path to one symbol/date's daily Databento MBP-10 parquet file.

eg: .uqfdata.databentoFile[`AAPL;2026.02.25]
Return: an hsym (file symbol) - the file need not exist yet
Parameters:
  • date - a q date, e.g. 2026.02.25
  • sym - ticker symbol, e.g. `AAPL`

.uqfdata.env

Parsed contents of the repo-root .env file, if present - see parseEnv.

.uqfdata.getBySymbolDate

Open one symbol/date's Databento parquet file as a lazy, row-group-pruned virtual table (via pqModule) - select from it like a normal table, e.g. select avg price by 1 xbar ts_event.minute from .uqfdata.getBySymbolDate[`AAPL;2026.02.25]

eg: .uqfdata.getBySymbolDate[`AAPL;2026.02.25]
Return: a virtual table handle over the matching parquet file
Parameters:
  • date - a q date, e.g. 2026.02.25
  • sym - ticker symbol, e.g. `AAPL`
throws: fileNotFound if no file exists for that symbol/date

.uqfdata.parseEnv

Parse a .env-style file (KEY=VALUE lines; blank lines and lines starting with `#` are ignored) into a dict. Missing file -> empty dict, so this is safe to call unconditionally at load time.

eg: .uqfdata.parseEnv[`:.env]
Return: a symbol!string dict of the parsed key/value pairs
Parameters:
  • file - the .env file to parse, e.g. `:.env`

.uqfdata.pqm

KX's official pq module (github kx.com KDB-X distribution), loaded and memoized on first use rather than at file-load time, so simply loading data.q doesn't require a module-capable interpreter.

eg: .uqfdata.pqModule[][`pq]
Return: the pq module namespace, exposing `.pq` (open file), `.op`/`.rd` (low-level access)
throws: if `use` (KDB-X's module loader) is unavailable - real kdb+/KDB-X is required here, not PeachQ
